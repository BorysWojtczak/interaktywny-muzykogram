Preferowany host (bez GitHuba): **https://muzykogram.apps.grok.bot**

Co sprawdzić:
1. Picker tematów pogrupowany: 3–4 / 4–5 / 5–6 lat

3. 5–6 lat: do 10 szlaczków

5. Pałeczka = iluzja (hint na tablicy)

Lokalnie: `npm install && npm run dev` (lub `npm run build && npm run preview`).
